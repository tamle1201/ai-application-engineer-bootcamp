## Ngày 99: 11/01/2027 (Thứ 2) - Nhập môn Docker
* **Sáng (Học gì):** 
  * Khái niệm Containerization. Sự khác biệt giữa Docker và Máy ảo (Virtual Machine).
  * `Dockerfile` là gì?
* **Chiều (Thực hành gì):** 
  * Cài đặt Docker Desktop.
  * Viết một file `Dockerfile` siêu đơn giản để chạy 1 script Python Hello World.
* **Đạt khi nào (PASS):** 
  * Chạy `docker build` và `docker run` thành công, máy ảo tự in ra chữ mà không cần cài sẵn Python trên máy Host.

## Ngày 100: 12/01/2027 (Thứ 3) - Dockerize Backend FastAPI
* **Sáng (Học gì):** 
  * Cách tối ưu image size (dùng slim-buster hoặc alpine). Cách phơi (expose) port ra ngoài.
* **Chiều (Thực hành gì):** 
  * Viết `Dockerfile` cho thư mục Backend. 
  * `pip install -r requirements.txt` bên trong container. Cấu hình gộp ChromaDB (lưu ý mapping Volume để giữ DB không bị xóa khi tắt container).
* **Đạt khi nào (PASS):** 
  * Backend chạy gọn gàng trong Docker, truy cập localhost:8000 bình thường.

## Ngày 101: 13/01/2027 (Thứ 4) - Build Frontend cho Production
* **Sáng (Học gì):** 
  * Lệnh `npm run build` hoạt động ra sao? Nó biến toàn bộ code React dài dòng thành vài file HTML/CSS/JS siêu nhẹ gọn.
* **Chiều (Thực hành gì):** 
  * Đổi các hardcode `http://localhost:8000` trong code React thành biến môi trường `import.meta.env.VITE_API_URL`.
  * Chạy lệnh build Frontend.
* **Đạt khi nào (PASS):** 
  * Thư mục `dist/` sinh ra các file tĩnh chuẩn bị để mang đi deploy.

## Ngày 102: 14/01/2027 (Thứ 5) - Deploy Frontend lên Vercel/Netlify
* **Sáng (Học gì):** 
  * Các nền tảng PaaS (Platform as a Service) miễn phí chuyên dành cho Fontend.
* **Chiều (Thực hành gì):** 
  * Đăng nhập Vercel bằng Github. Link cái repo Frontend của bạn vào.
  * Bấm 1 nút Deploy. 
* **Đạt khi nào (PASS):** 
  * Nhận được 1 đường link thật (vd: `my-rag-visualizer.vercel.app`), dùng điện thoại vào web được (tuy chưa gọi được api).

## Ngày 103: 15/01/2027 (Thứ 6) - Deploy Backend lên Render/Railway
* **Sáng (Học gì):** 
  * Render.com hoặc Railway.app là các nền tảng cho phép host Docker container miễn phí.
* **Chiều (Thực hành gì):** 
  * Kết nối repo Backend vào Render. Khai báo các API Key bí mật vào mục Environment Variables trên Web (tuyệt đối không push file .env lên).
  * Chờ Render build Docker image.
* **Đạt khi nào (PASS):** 
  * Backend có link public. Frontend gọi được vào link Backend đó bình thường.
