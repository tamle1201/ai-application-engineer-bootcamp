## Ngày 86: 29/12/2026 (Thứ 3) - Parsing JSON API sang React Flow
* **Sáng (Học gì):** 
  * API trả về JSON chứa `claims`, `evidences`, `status`. Nhưng React Flow cần mảng `nodes` và `edges` có tọa độ.
  * Hàm `Transformer`: Kỹ thuật viết một hàm kẹp ở giữa để chuyển đổi data Backend thành data Frontend.
* **Chiều (Thực hành gì):** 
  * Viết file `dataTransformer.js`. 
  * Duyệt qua mảng `claims` từ API, biến mỗi claim thành một object `{ id: 'c1', type: 'ClaimNode', data: { label: claim.text, status: claim.color } }`.
  * Tạo các `edges` nối từ Câu trả lời -> Các Claims.
* **Tối (Nộp gì):** 
  * File code `dataTransformer.js`.
* **Đạt khi nào (PASS):** 
  * Chạy unit test (bằng `console.log`) đầu vào là JSON của API, đầu ra là mảng Nodes/Edges chuẩn của React Flow.
