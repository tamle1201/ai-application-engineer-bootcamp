## Ngày 50: 23/11/2026 (Thứ 2) - Ráp nối Retrieval vào Prompt
* **Sáng (Học gì):** 
  * Cơ chế "In-context Learning". Làm sao để nhồi Context (từ Retrieval) vào System Prompt một cách tự nhiên nhất mà LLM không bị ngộp?
  * Vai trò của ký tự ngăn cách (Ví dụ dùng `<context></context>` XML tags) để LLM dễ nhận diện.
* **Chiều (Thực hành gì):** 
  * Viết một luồng code chạy từ A-Z: 
    1. Nhận query của user.
    2. Gọi class `Retriever` (Tuần 7) tìm top 3 chunk.
    3. Nối 3 chunk thành 1 chuỗi text lớn.
    4. Bơm chuỗi text đó vào Prompt (Tuần 6).
    5. Gọi LLM API để lấy câu trả lời.
* **Tối (Nộp gì):** 
  * Script Python chạy RAG hoàn chỉnh trên Terminal.
* **Đạt khi nào (PASS):** 
  * Hỏi AI một câu về Quy chế, nó trả lời vanh vách và thông tin khớp 100% với tài liệu bạn cung cấp, không có tình trạng tự bịa ra luật mới.

## Ngày 51: 24/11/2026 (Thứ 3) - Thiết kế Dữ liệu API (Pydantic Models)
* **Sáng (Học gì):** 
  * Làm sao để trả về cho Frontend (React Flow sau này) những metadata hữu ích thay vì chỉ trả về 1 cục Text?

* **Chiều (Thực hành gì):** 
  * Định nghĩa `ChatRequest` model (chứa `query` và `session_id`).
  * Định nghĩa `ChatResponse` model (chứa `answer` (str), `sources` (List[str])).
  * Bọc lại luồng code Ngày 50 vào trong một class trung tâm `RAGService`.
* **Tối (Nộp gì):** 
  * File code `schemas.py` và `services.py`.
* **Đạt khi nào (PASS):** 
  * Class `RAGService` gọi hàm là trả về ngay Pydantic Object rất tường minh.

## Ngày 52: 25/11/2026 (Thứ 4) - Mở cổng FastAPI
* **Sáng (Học gì):**

* **Chiều (Thực hành gì):**

  * Bơm `RAGService` vào qua Dependency Injection. 
  * Nhận câu hỏi qua API, xử lý và trả về JSON chuẩn.
* **Tối (Nộp gì):**

* **Đạt khi nào (PASS):**

## Ngày 53: 26/11/2026 (Thứ 5) - Quản lý Lịch sử Chat (Conversational Memory)
* **Sáng (Học gì):** 
  * Nhược điểm của API: Nó là "Stateless" (Không nhớ gì cả).
  * Làm sao để RAG nhớ câu hỏi trước? (Phải đẩy toàn bộ lịch sử n-tin-nhắn vào mảng messages trước khi gọi LLM).
* **Chiều (Thực hành gì):** 
  * Tạo một Dictionary tạm thời trong RAM (hoặc lưu SQLite ngắn hạn) để lưu list các tin nhắn theo `session_id`.
  * Trước khi gọi LLM, lấy history ra, append câu hỏi mới vào.
* **Tối (Nộp gì):** 
  * Code API hỗ trợ giữ ngữ cảnh hội thoại.
* **Đạt khi nào (PASS):** 
  * Lượt 1 hỏi "Sinh viên bị đuổi học khi nào?", AI trả lời. Lượt 2 hỏi "Vậy thì quy chế đối với sinh viên đó ở kỳ hè ra sao?", AI vẫn hiểu "sinh viên đó" là sinh viên bị đuổi học.

## Ngày 54: 27/11/2026 (Thứ 6) - Formatting và Ép Trích Dẫn (Citations)
* **Sáng (Học gì):** 
  * Kỹ năng Prompt Nâng Cao: Bắt AI phải đính kèm ID của nguồn vào cuối mỗi câu nó tham khảo (ví dụ: "[Doc 1]").
* **Chiều (Thực hành gì):** 
  * Sửa lại System Prompt: Cung cấp tài liệu ở dạng `<doc id="1">Nội dung</doc>`. Ép AI thêm dấu ngoặc vuông chứa ID sau mỗi câu nó tóm tắt.
  * Phân tích câu trả lời, trả về danh sách map ID với chunk để UI hiển thị đẹp.
* **Tối (Nộp gì):** 
  * System Prompt phiên bản ép trích dẫn.
* **Đạt khi nào (PASS):** 
  * AI không bao giờ nói khơi khơi. Cứ hết 1 câu là có citation `[1]`, `[2]` đính kèm cực kỳ học thuật.
