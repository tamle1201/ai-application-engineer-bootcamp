## Ngày 36: 09/11/2026 (Thứ 2) - Căn bản về Structured Output
* **Sáng (Học gì):** Cách prompt LLM để trả về định dạng đặc thù. Khái niệm JSON Schema.
* **Chiều (Thực hành gì):** Viết Prompt yêu cầu phân tích 1 câu văn thành JSON `{ "chu_ngu": "...", "vi_ngu": "..." }`. Dùng Regex học ở Tuần 3 để bóc tách JSON ra khỏi chuỗi text.
* **Tối (Nộp gì):** Script extract JSON bằng regex.
* **Đạt khi nào (PASS):** Lấy đúng được đoạn JSON ở giữa mớ văn xuôi dài dòng.
