## Ngày 71: 14/12/2026 (Thứ 2) - Khởi tạo Dự án & Kiến trúc Component
* **Sáng (Học gì):** 
  * Cài đặt `Node.js` và trình quản lý package `npm`.
  * Công cụ `Vite` là gì và tại sao nó đánh bại Create-React-App?
  * Khái niệm "Component-based" (Mọi thứ trên màn hình đều là các mảnh ghép nhỏ).
  * Cú pháp JSX: Trộn lẫn HTML vào bên trong file Javascript (hoặc Typescript).
* **Chiều (Thực hành gì):** 
  * Chạy lệnh `npm create vite@latest frontend -- --template react` để tạo project mới.
  * Xóa hết code rác mặc định của Vite. Tự viết 2 Component: `<Header />` (Tiêu đề ứng dụng) và `<ChatWindow />` (Khung chat tạm thời trống rỗng).
  * Chạy `npm run dev` để xem trên trình duyệt.
* **Tối (Nộp gì):** 
  * Ảnh chụp màn hình trình duyệt có chữ "Hello RAG Visualizer".
* **Đạt khi nào (PASS):** 
  * Hiểu được quy luật: Tên Component bắt buộc phải viết hoa chữ cái đầu, và một Component chỉ được return về duy nhất 1 thẻ cha bọc ngoài (thẻ div hoặc fragment `<>...</>`).

## Ngày 72: 15/12/2026 (Thứ 3) - Lưu trữ Trạng thái (State) & Truyền Dữ liệu (Props)
* **Sáng (Học gì):** 
  * Concept cốt lõi số 1 của React: Hook `useState`. Giao diện tự động thay đổi khi State thay đổi.
  * Concept cốt lõi số 2: Truyền dữ liệu từ Component cha xuống con thông qua `Props`.
* **Chiều (Thực hành gì):** 
  * Tạo biến state `const [messages, setMessages] = useState([])` bên trong `<ChatWindow />`.
  * Khởi tạo mảng `messages` chứa 2 câu thoại mẫu (1 của user, 1 của AI).
  * Dùng vòng lặp `messages.map(...)` để render (hiển thị) mảng này ra màn hình, phân biệt màu sắc tùy theo `role`.
* **Tối (Nộp gì):** 
  * Code logic map list tin nhắn.
* **Đạt khi nào (PASS):** 
  * Thêm 1 object vào mảng `messages` trong code, màn hình tự động hiển thị thêm 1 dòng chat mà không cần F5 trình duyệt.

## Ngày 73: 16/12/2026 (Thứ 4) - Tương tác Người dùng (Forms & Events)
* **Sáng (Học gì):** 
  * Bắt sự kiện `onChange` (khi gõ phím) và `onSubmit` (khi nhấn Enter/Gửi).
  * Kiểm soát thẻ Input (`Controlled Components`) - Gắn giá trị của input vào 1 biến State.
* **Chiều (Thực hành gì):** 
  * Tạo Component `<ChatInput />`.
  * Viết biến `const [inputValue, setInputValue] = useState('')`. Ràng buộc nó vào thẻ `<input>`.
  * Viết hàm `handleSend`: Khi user nhấn nút, đẩy `inputValue` vào mảng `messages` của ngày hôm qua, sau đó xóa trống ô input.
* **Tối (Nộp gì):** 
  * Code giao tiếp giữa nút bấm và mảng dữ liệu.
* **Đạt khi nào (PASS):** 
  * Gõ chữ -> Bấm Enter -> Chữ nhảy lên màn hình chat -> Ô nhập liệu trở về trống rỗng.

## Ngày 74: 17/12/2026 (Thứ 5) - Side Effects & Lấy dữ liệu API (useEffect)
* **Sáng (Học gì):** 
  * Hook `useEffect`: Dùng để làm những việc "thoát ra khỏi vòng tuần hoàn UI", ví dụ như gọi API Backend.
  * Tại sao gọi API trong React lại dễ sinh ra lỗi "Infinite Loop" (vòng lặp vô tận) nếu quên Dependency Array `[]`?
* **Chiều (Thực hành gì):** 
  * Thay vì gửi tin nhắn ảo, hãy sửa hàm `handleSend` để sử dụng `fetch()` hoặc `axios`.
  * Gọi thử vào endpoint `POST /api/chat` (FastAPI backend bạn làm ở Tuần 10). Tạm thời in kết quả JSON API trả về ra `console.log`.
* **Tối (Nộp gì):** 
  * Script gọi API tích hợp.
* **Đạt khi nào (PASS):** 
  * Bấm nút gửi ở web (React), Terminal của backend (FastAPI) nhận được log request, và React console nhận được response JSON. Chắp nối thành công Fontend - Backend!
