# Kế hoạch học tập - Ngày 1 (15/09/2026)
**Chủ đề:** Khởi động Phase 1 - Type Hints & Pydantic trong Python

## 🎯 Mục tiêu trong ngày
- Nắm vững cách khai báo kiểu dữ liệu khắt khe trong Python (Type Hints).
- Hiểu và sử dụng được thư viện Pydantic để validate (kiểm chứng) dữ liệu.
- Viết được đoạn code định nghĩa các class chuẩn xác, không chấp nhận dữ liệu rác.

## 🕒 Lịch trình chi tiết

### 🌞 Sáng (8h00 - 11h00): Lý thuyết
- Đọc tài liệu về [Python Type Hints (typing)](https://docs.python.org/3/library/typing.html). Hiểu các kiểu cơ bản: `List`, `Dict`, `Optional`, `Union`, `Callable`.
- Đọc tài liệu cơ bản của [Pydantic](https://docs.pydantic.dev/latest/).
- **Kiểm tra độ hiểu:** Tại sao Python cần Type Hints trong khi nó là ngôn ngữ dynamic (gõ động)? Sự khác biệt giữa `dataclass` và `Pydantic` là gì?

### 🌤️ Chiều ca 1 (13h30 - 16h30): Code Lab & Debug
- Cài đặt môi trường ảo (virtual environment) bằng `venv` hoặc `uv`.
- Cài đặt `pydantic`.
- **Thực hành 1:** Khai báo một hàm tính toán cơ bản có gán type hint cho đầu vào và đầu ra. Dùng `mypy` để check lỗi.
- **Thực hành 2:** Xây dựng mô hình (Model) bằng Pydantic cho một `User` (Gồm: ID, Tên, Email chuẩn form, Tuổi phải lớn hơn 18). Cố tình truyền sai dữ liệu để xem Pydantic văng lỗi (Validation Error) như thế nào.
