# LỘ TRÌNH AI APPLICATION ENGINEER

Lộ trình được chia làm 7 Phase (A-G). Trong đó, Phase A, B, C, D tập trung vào việc học kiến thức nền tảng (tổng cộng 6 tuần). Các Phase E, F, G dành cho việc nghiên cứu, xây dựng và triển khai dự án thực tế.

Cấu trúc phần "Kiến thức" trong mỗi Phase học được tổ chức thành các **Program**, trong mỗi Program gồm nhiều **Course**, mỗi Course có các **Unit**, **Tài liệu (docs)**, và **Running Project** như mô hình chuẩn.

---

## PHASE A: Python Programming for AI (Thời gian học: 1 tuần)

**Chương trình học (Program):** Python Programming for AI
* **Mục tiêu (Note):** Học kỹ nền tảng, giải thích được bằng code và giải thích được code AI tạo ra. Hoàn thành 1 milestone trong running project.

* **Course 1: Python Programming**
  * **Unit/Docs:** Async, Advanced features.
  * **Course Learning Outcome:** Nắm vững tính năng nâng cao của Python.
* **Course 2: Python Libraries for Data & AI**
  * **Unit/Docs:** Numpy, Pandas, Seaborn, Matplotlib.
  * **Course Learning Outcome:** Làm chủ các thư viện xử lý dữ liệu.

**Running Project Phase A:**
* **Mục tiêu:** Hoàn thành 1 project liên quan đến dữ liệu.
* **Output:** Tạo 1 web xử lý data với Python.

---

## PHASE B: Web Development with Python & FastAPI & ReactJS/NextJS (Thời gian học: 2 tuần)

**Chương trình học (Program):** Web Development with Python & FastAPI & ReactJS/NextJS
* **Mục tiêu (Note):** Học kỹ nền tảng Web, sử dụng Framework xây dựng web.

* **Course 1: Database**
  * **Unit/Docs:** SQL, No-SQL.
  * **Course Learning Outcome:** Hiểu và thao tác được với cơ sở dữ liệu.
* **Course 2: Internet Basic**
  * **Unit/Docs:** HTTP, Network, OS.
  * **Course Learning Outcome:** Nắm vững kiến thức mạng cơ bản, giao thức HTTP.
* **Course 3: Web API Framework - FastAPI**
  * **Unit/Docs:** Sử dụng Framework xây dựng web, RESTful API, GraphQL, ORM Framework.
  * **Course Learning Outcome:** Xây dựng được Backend API với FastAPI.
* **Course 4: Frontend**
  * **Unit/Docs:** ReactJS Core, NextJS, Tailwind CSS.
  * **Course Learning Outcome:** Xây dựng giao diện web hiện đại.

**Running Project Phase B:**
* **Mục tiêu:** Hoàn thành 1 project Web.
* **Output:** Web application hoàn chỉnh kết nối Frontend và Backend FastAPI.

## PHASE C: Ứng dụng AI trong Phát triển phần mềm (Thời gian học: 1 tuần)

**Chương trình học (Program):** Ứng dụng AI trong Phát triển phần mềm
* **Mục tiêu:** Nắm vững nền tảng AI và quy trình phát triển phần mềm có AI hỗ trợ.

* **Course 1: Nền tảng về AI**
  * **Unit/Docs:** Instruction, Prompt, Context, Memory, Skill, Hook.
  * **Course Learning Outcome:** Hiểu và áp dụng được các thành phần cốt lõi để tương tác hiệu quả với AI/LLM.
* **Course 2: Software Development Lifecycle (SDLC)**
  * **Unit/Docs:** CI/CD, Spec Driven Development (AWS AI DLC, Spec Kit), Agile Scrum, Ứng dụng AI trong quy trình SDLC.
  * **Course Learning Outcome:** Nắm vững vòng đời phát triển phần mềm hiện đại và cách tích hợp AI vào quy trình.

**Running Project Phase C:**
* **Mục tiêu:** Tích hợp quy trình tự động hóa/AI vào phát triển phần mềm.

---

## PHASE D: AI Application Architecture & LLM (Thời gian học: 2 tuần)

**Chương trình học (Program):** AI Application Architecture & LLM
* **Mục tiêu:** Hiểu và xây dựng được hệ thống RAG và hệ thống AI Agent hoàn chỉnh.

* **Course 1: AI Application Architecture**
  * **Unit/Docs:** Loop, Harness.
  * **Course Learning Outcome:** Thiết kế kiến trúc cho ứng dụng AI.
* **Course 2: RAG System (Retrieval-Augmented Generation)**
  * **Unit/Docs:** Ingestion (OCR, Vision), Chunking, Embedding, Indexing, Retrieval (Reranker).
  * **Course Learning Outcome:** Xây dựng hệ thống RAG từ xử lý dữ liệu thô đến truy xuất nâng cao.
* **Course 3: AI Agent System**
  * **Unit/Docs:** AI Application Architecture + App.
  * **Course Learning Outcome:** Xây dựng Agent tự trị.
* **Course 4: LLM Architecture**
  * **Unit/Docs:** Encoder, Decoder, Transformer.
  * **Course Learning Outcome:** Hiểu sâu về cấu trúc của LLM.

**Running Project Phase D:**
* **Mục tiêu:** Xây dựng ứng dụng AI RAG/Agent.
* **Output:** Hệ thống truy vấn thông minh kết hợp RAG.

## PHASE E: Nghiên cứu làm dự án
* Bắt đầu giai đoạn làm dự án thực tế. Lên ý tưởng, nghiên cứu tính khả thi, phân tích yêu cầu.

---

## PHASE F: Xây dựng sản phẩm
* Trực tiếp lập trình, tích hợp các module (Frontend, Backend, AI models, RAG pipeline) để tạo thành một sản phẩm hoàn thiện theo chuẩn.

---

## PHASE G: Triển khai (Deployment & Operations)
* **DevOps cơ bản:**
  * OS, Linux (shell, bash...), Networking.
  * Containerization (Docker, Compose).
  * AWS / Azure / GCP Services & IaC (Terraform).
  * CI/CD / DevSecOps.
  * Kubernetes / GitOps (Cơ bản).
  * Observability / SRE / AIOps / ChatOps (Cơ bản).
* **Triển khai LLMOps / MLOps:**
  * Đưa mô hình AI và hệ thống ứng dụng lên môi trường Production, đảm bảo theo dõi và vận hành ổn định.
